# proyectadas_cartesianas
\u222B2x game: A modification of freegames "Cannon.py: Cannon, hitting targets with projectiles"

Este es un juego de catapulta donde el punto rojo debe golpear a las bolas azules, el proyectil se dirige con el mouse. 
Los cambios que se hicieron fueron:
La velocidad del proyectil (rojo) y los balones (azul) se hizo más rápida.
Se modificó el código para que cuando los balones lleguen al final el juego se reinicié, esto hace al juego infinito.

Como sugerencia en futuras modificaciones se puede añadir un contador de puntos.
